# 小心意 · 家庭礼物柜

用于两位安卓用户的礼物库存工具，目前是手机网页简单版，先验证筛选与记录流程。

已确认的方向：先按标签筛选；没有合适的物品时逐个删除标签，或一键清空查看所有可送物品。示例为冰箱贴与拉布布；内置名称、数量和插画均不代表真实家庭库存或官方商品信息。

界面采用白色、浅灰和少量蓝色操作色，优先清晰的文字、留白与一致的触控区域。去除宣传式英文、礼盒装饰及绿色主题；底栏只切换页面，添加物品放在页头。布局参考 Apple Human Interface Guidelines，当前实现仍是面向安卓使用的网页原型。

## 使用

在此目录运行 `node server.mjs`，打开 `http://127.0.0.1:4318/`。服务仅在本机监听。静态页面位于 `dist/`，无需安装依赖。

第一版包括可增删的物品标签、照片录入与压缩、名称与位置搜索、库存数量、送出记录、撤销送出，以及备份导入导出。同组筛选标签使用“任一符合”，不同组需要同时符合。

## GitHub 共享存储

应用地址：https://wa1king.github.io/family-gift-cabinet/

公开仓库 `wa1king/family-gift-cabinet` 只放应用代码。清单、照片和送出记录存入独立私有仓库 `wa1king/family-gift-cabinet-data`，不再将手机本地数据当作共享清单。无需 Supabase，也无需家中电脑开机。

首次连接：

1. 在 GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens 新建专用授权。
2. 仅选择 `family-gift-cabinet-data`，Contents 权限为 Read and write，其他权限保持默认，设置有效期。
3. 把生成的 token 填入应用的连接框；不要发到聊天，也不要写入配置或代码。另一台手机用同一数据仓库的专用授权连接。
4. 默认仅在本次浏览器会话保存授权；只有主动勾选“在这台私人设备上记住授权”才保存到当前浏览器。断开设备会移除本机授权；在 GitHub 撤销 token 可使所有使用它的设备失去访问权限。
5. 云端为空时，可主动迁移这台手机原有的本机清单，或从空柜子开始。不会自动上传内置示例、真实物品或本机照片。第二台有不同本机数据时，先导出备份再整理导入，导入会替换共享清单。

公开配置 `dist/github-config.js` 仅包含仓库坐标。运行时 token 只发往 `api.github.com`，不发往其他服务；公开代码不包含凭据。页面限制脚本、网络与图片来源。当前是手机网页应用，不是安卓安装包。

## 保存和恢复

清单保存在 `cabinet.json`，照片按内容 SHA-256 存在 `photos/`。一次保存先创建照片与清单的 Git tree/commit，再以非强制快进更新分支，因此照片与清单一同可见。两台设备同时修改时后保存的一方会收到冲突，输入保留，禁止静默覆盖。

保存回执丢失时，通过操作编号核对，未确认前阻止新修改。前台定时检查最新版本，并在重新联网或返回应用时刷新。尚未连接网络时不会把修改报告为已保存。连接需要 GitHub 可达，授权过期需更新；不提供离线编辑队列。

导出文件包含真实照片和送出记录，可用于迁移；导入前请核对替换范围。设置提供恢复上一版。Git 历史和旧照片仍保留在私有仓库，普通编辑、替换和恢复不会永久清除历史。

旧 Supabase 文件仅保留在源仓库作为未启用的历史实现；当前发布不包含或加载它们。

## 验证

运行 `npm test` 验证筛选、库存、撤销、备份、GitHub 并发保存和断网恢复规则。`tests/fixtures/` 内的 JSON 和图片仅供浏览器试用验证。预览截图与验证记录保存在本地忽略目录 `qa/`。

真实 GitHub 接口已在独立 QA 分支使用合成数据验证跨客户端读写、照片字节往返、数量更新、并发拒绝、幂等重试和上一版恢复；未修改主分支清单。正式使用仍需在手机中完成访问授权和首次迁移。QA 分支只包含合成验证数据。朋友偏好档案仍待讨论。
