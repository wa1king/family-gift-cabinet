# 小心意 · 家庭礼物柜

一个适合手机浏览器使用的家庭礼物清单原型。记录家里可送人的物品，按喜好、场合和礼物分量筛选，保存送出记录。

## 当前功能

- 一个礼物柜页面完成浏览、搜索和挑选，按类别、场景、关系和价值展开筛选。
- 筛选入口收成一行，物品优先展示；底部保留礼物柜、送出记录两个入口。
- 管理标签：新增、改名、删除和撤销；改名与删除会同步到相关物品。
- 新增标签和类别时才展开输入框，支持自定义物品类别。
- 记录照片、数量、存放位置、备注和标签。
- 数量统一记录，不需要填写单位。
- 支持拍照或从相册选择照片。
- 送出后扣减数量，保留记录并支持撤销。
- 导出、导入备份。

## 数据保存

仓库只含应用代码和虚构示例，不包含真实家庭物品、照片或送出记录。你在应用中填写的数据保存在当前设备、当前浏览器的本地存储中，不上传到 GitHub。

兼容旧版备份：原“场合”归入“场景”，原“喜好”保留在物品备注，关系留待自行填写。

新版支持自定义类别，并按用户要求去掉单位字段；升级保留数量、照片、备注、标签和送出记录。

这是试用原型，暂不支持两人实时同步。清理浏览器数据、换浏览器或换网址后，原有清单不会自动出现；请使用应用中的备份导出和导入功能。上传自己的照片后也请定期备份。

## 运行与部署

这是无需安装依赖和构建的静态网页。使用任意静态文件服务器打开仓库根目录即可运行。

GitHub Pages 使用 `main` 分支的根目录 `/` 发布。页面资源均为相对路径，适用于项目子路径；`.nojekyll` 用于直接提供静态文件。
